# Explore Mundo - Aplicativo de Agência de Viagens

Trabalho Prático | DGT2812 - Desenvolvimento de Aplicativos Móveis com Flutter

App Flutter da agência fictícia **Explore Mundo**: banner de destaque interativo,
barra de navegação (Destinos, Pacotes de viagem, Contato, Sobre nós), pesquisa
rápida, páginas de destino com avaliação em estrelas e reserva simulada.

## Estrutura

- `lib/main.dart` - aplicativo final
- `lib/microatividades/` - micro2 (MaterialApp/Scaffold/AppBar), micro3 (Row/Column), micro4 (ListView), micro5 (Stack)
- `images/` - imagens do app
- `test/widget_test.dart` - teste de widget
- `docs/` - documentação do projeto (PDF)

## Como executar

```bash
flutter pub get
flutter run -d chrome
flutter run -t lib/microatividades/micro2.dart   # uma microatividade
flutter test
```
